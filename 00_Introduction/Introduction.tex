\chapter*{Preface}
I've repeatedly found myself going back to various books,
resources and various materials trying to remember design
equations, advantages, disadvantages are for a particular
building block. \textbf{This is frustrating and time-consuming.}

It would thus be really helpful to have a single living
resource an designer like me can seek which contains all
known fundamental building blocks in the most designer
friendly way possible (raw mathematics, little theory).
This handbook is my attempt at creating such a utopoian
resource.

You \textbf{should be familiar with basic electronics
concepts like Kirchhoff's Laws and Control Systems
before using this Handbook}. A small amount of theory
that I believe is important is still included in Chapter
\ref{ch:theory}.
