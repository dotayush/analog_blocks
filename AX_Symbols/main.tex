\section{Notation}\label{sec:notation}
Greek letters are kept only for units and for universal constants and
angles (\(\Omega\), \(\pi\), \(\omega = 2\pi f\), \(\theta\), \(\phi\),
\(\psi\), the micro prefix \(\mu\)). Every quantity that a designer
chooses or a device exhibits is written with english letters.

\noindent Other conventions:
\begin{enumerate}
  \item Voltages and currents are always written with capital letters.
    Large signal quantities carry upper case subscripts (\(V_{GS}\),
    \(I_D\)); small signal quantities carry lower case subscripts
    (\(V_{gs}\), \(I_d\)), so a node \(V_x\) has the bias value \(V_X\). In linear
    blocks, where one derivation serves both, the analysis heading (Large
    Signal, Time Domain, DC Input Analysis (Q5) or Small Signal, Frequency
    Domain, AC Input Analysis (Q4)) decides which is meant.
  \item Conductances \(G = 1/R\), \(g_m\), \(g_o = 1/r_o\) are preferred
    over resistances since KCL is written in conductances.
  \item \(A \parallel B = \dfrac{AB}{A + B}\).
\end{enumerate}

\section{Symbols and Labels}\label{sec:symbols}
Every symbol and label used in the notebook, listed once. Letters that
change meaning between chapters are collected in the first group; an
indexed symbol (\(g_{m_k}\), \(b_k\), \(V_{out_k}\)) stands for all its numbered
members, and three rules cover the rest without repeating entries:
\begin{enumerate}
  \item a symbol with upper case subscripts is the large signal (bias) value of
    the listed small signal symbol (\(V_{O1}\) of \(V_{o1}\), \(V_G\) of \(V_g\)), and a
    \((Q)\) subscript marks the bias point;
  \item \(d\) in front of a symbol is a small change of it (\(dV_{OUT}\), \(dR_{out}\));
  \item letters written side by side are a product (\(sC_L\), \(aD\), \(kTR\)).
\end{enumerate}
