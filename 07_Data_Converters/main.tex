\chapter{Data Converters}\label{ch:data_converters}

A data converter moves a signal between the continuous (analog) and the
discrete (digital) world. A Digital to Analog Converter (DAC) maps an
\(n\)-bit code onto one of \(2^n\) analog levels. An Analog to Digital
Converter (ADC) maps an analog level onto the \(n\)-bit code whose level
is closest to it.
