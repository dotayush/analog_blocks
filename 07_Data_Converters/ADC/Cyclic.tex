\subsection{Cyclic (Algorithmic) ADC}\label{sec:adc_cyclic}

\subsubsection{Overview}
One pipeline stage whose residue is fed back to its own input: the same
hardware produces one bit (or 1.5 bits) per clock cycle. \(n\) cycles per
conversion, minimal area.

\subsubsection{Transfer Function}
\textbf{Large Signal, Time Domain, DC Input Analysis (Q5)}: with the 1-bit
stage over \([0, V_{REF})\), \(V^{(0)} = V_{IN}\):
\begin{align*}
  b_k &= \begin{cases} 1 & V^{(k-1)} \geq \frac{V_{REF}}{2} \\ 0 & \text{otherwise} \end{cases} \hspace{1cm}
  V^{(k)} = 2 V^{(k-1)} - b_k V_{REF} \\
  V_{IN} &= V_{REF}\sum_{k=1}^{n} b_k 2^{-k} + \frac{V^{(n)}}{2^n}
\end{align*}
(the pipeline recursion of Section~\ref{sec:adc_pipeline} indexed by time).

\subsubsection{Analysis}
\begin{enumerate}
  \item The same gain error \(e\) is applied every cycle, so
    \(V^{(n)}\) carries \((2(1 + e))^n\); errors do not average as in a
    pipeline with independent stages but accumulate through one stage.
  \item Conversion rate \(\frac{f_{clk}}{n}\) (one bit per cycle) or
    \(\frac{f_{clk}}{n/2}\) with two half-cycle operations.
\end{enumerate}
