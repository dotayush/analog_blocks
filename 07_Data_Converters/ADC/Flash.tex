\subsection{Flash ADC}\label{sec:adc_flash}

\subsubsection{Overview}
A resistor string makes all \(2^n - 1\) thresholds at once and \(2^n - 1\)
comparators compare \(V_{IN}\) against all of them in one clock. The
comparator outputs form a thermometer code that is encoded to binary.
Fastest architecture, cost exponential in \(n\) (rarely above 6--8 bits).

\subsubsection{Transfer Function}
\textbf{Large Signal, Time Domain, DC Input Analysis (Q5)}: with
\(\frac{R}{2}\) end resistors the string has \((2^n - 1) R + R = 2^n R\) total
and thresholds at
\[
  V_{T,k} = \frac{\frac{R}{2} + (k - 1) R}{2^n R} V_{REF} = \left(k - \frac{1}{2}\right) X_{LSB}, \hspace{1cm} k = 1 \ldots 2^n - 1
\]
exactly the ideal transitions of Section~\ref{sec:dc_char}. Comparator \(k\)
outputs \(T_k = 1\) if \(V_{IN} > V_{T,k}\); \(D = \sum_k T_k\).

\subsubsection{Analysis}
\begin{enumerate}
  \item \textbf{Comparator Offset}: offset \(V_{os,k}\) moves transition \(k\):
    \(DNL_k = \frac{V_{os,k+1} - V_{os,k}}{X_{LSB}}\),
    \(SD(DNL) = \frac{\sqrt{2}\, SD(V_{os})}{X_{LSB}}\). No missing codes with
    \(\approx 3\)SD margin needs \(SD(V_{os}) < \frac{X_{LSB}}{3\sqrt{2}}\).
  \item \textbf{Bubbles}: metastability or offset can give \(\ldots 1101 \ldots\)
    (a 0 inside the 1s); a 3-input majority gate per position removes single
    bubbles before encoding.
  \item \textbf{Cost}: \(2^n - 1\) comparators, input capacitance
    \((2^n - 1) C_{in,comp}\), power \(\propto 2^n\).
\end{enumerate}

\subsubsection{Question}
A 6-bit flash with \(V_{REF} = 1\,\)V. Find \(X_{LSB}\), the comparator count and
the offset SD for no missing codes.
\paragraph{Solution:}
\(X_{LSB} = \frac{1}{64} = 15.6\,\)mV, 63 comparators,
\(SD(V_{os}) < \frac{15.6}{3\sqrt{2}} = 3.7\,\)mV.
